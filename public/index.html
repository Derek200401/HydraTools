Setup

Five steps, no root

Shizuku is the only thing you install first. Everything else is inside HydraTools.

Get Shizuku
  1. 1

    Install and start Shizuku

    Start the service from the Shizuku app. On Android 11 and up you can use wireless debugging.

  2. 2

    Download the APK

    Use the download button below. Android asks you to allow installs from your browser the first time.

  3. 3

    Open HydraTools

    Allow the Shizuku permission request when it appears.

  4. 4

    Apply a patch

    Open Config or Skin, pick an item, read the Patch Preview, then slide to apply.

  5. 5

    Play, or undo

    Open Mobile Legends. To get the original files back, run Backup / Restore.

FAQ

Quick answers

Do I need root?

No. HydraTools works through Shizuku, so your phone stays unrooted.

Do I need a virtual space or a cloned game?

No. You use the normal Mobile Legends you already have installed.

What is Shizuku?

A free app that lets other apps run system-level actions after you start it, for example with wireless debugging on Android 11 and up. Get it from shizuku.rikka.app.

How do I undo a patch?

Open Config, then Backup / Restore. It reverts all gameplay patches and system tweaks, restores the original Document.unity3d and keeps your downloaded game resources.

What do FREE and VIP mean?

They are the tags shown inside the app. FREE items are open to everyone, VIP items are marked VIP in HydraTools.

Why does Android warn me when I install it?

Because the APK doesn’t come from the Play Store. Check that the SHA-256 on this page matches your file before you install.

Which game version does it work with?

The dashboard shows the game version and region the app finds. The screenshots here are from 2.2.16.12322 on the Philippines server. Game updates can change things, so message me if a patch stops working.
